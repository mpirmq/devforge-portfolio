ENGLISH OVERVIEW

A local IT support workspace

SupportDesk combines ticket creation, priority and status management, activity history, solution notes, dashboard metrics and CSV export. Restricted DNS, TCP and HTTPS diagnostics attach findings to the ticket.

Built with the Python standard library, SQLite and plain JavaScript. This is a personal portfolio project, not a client commission or production multi-user service. Download the ZIP, install Python 3.10+, run python app.py and open the local address shown above.

The browser demo also includes real SQLite analytics: SELECT, GROUP BY and JOIN on a read-only snapshot of demo tickets and activity. SQL runs locally through WebAssembly, with a result limit and execution timeout. This browser feature is separate from the downloadable Python application.

Four automated backend tests cover the local application workflow. SQL checks cover selection, JOIN, error handling, write rejection and result limits; SELECT, JOIN, grouping and write rejection were also verified in the published browser demo.
